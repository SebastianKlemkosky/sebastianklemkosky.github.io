# Sebastian Klemkosky — Pixel Biome Portfolio

A retro-inspired software engineering portfolio hosted on GitHub Pages.

## Website structure

- Level 1 — Surface: reserved for a future interactive endless runner
- Level 2 — Sewers: about me
- Level 3 — Underground: projects
- Level 4 — Lava: skills and contact

Built with HTML, CSS, and a little JavaScript. No framework or backend is required.

## Run locally

Open `index.html` or use VS Code Live Server.

## Deploy on GitHub Pages

Copy `index.html`, `styles.css`, `script.js` and `.nojekyll` to the root of `sebastianklemkosky.github.io`, then commit and push to `main`.
