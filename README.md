# Sebastian Klemkosky — Portfolio

A personal software engineering portfolio built with HTML, CSS, and JavaScript and hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Customize

- Edit `index.html` to change text, project cards, and links.
- Edit `styles.css` to change the look of the site.
- Edit `script.js` to add browser interactions.
- Place future demos in directories such as `projects/dungeon/`.
- Add your resume PDF later and link it from the homepage.

## Publish

Push these files to your `<username>.github.io` repository. In GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Notes

Project cards marked planned/in development are not live demos yet. Update links as your projects go live.
